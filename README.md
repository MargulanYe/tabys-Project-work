# Tabys.kz – Platform for Teen Freelancers in Kazakhstan

## 📌 Project Description
Tabys.kz is a web platform designed to connect clients with teenagers who have basic IT skills.

The platform allows users (clients) to post simple tasks such as:
- Excel work
- Presentations
- Document formatting
- Basic computer help

Teenagers can browse these tasks and complete them for payment.

## 🎯 Goal
To create opportunities for teenagers in Kazakhstan to earn money using their basic IT skills while helping people who struggle with technology.

## 💡 Key Idea
Unlike platforms like Upwork or Fiverr:
- Focuses on **simple tasks**
- Designed for **students and beginners**
- Localized for **Kazakhstan market**
- Easy entry without professional experience

## 👥 Target Users
- Clients: teachers, parents, small businesses
- Executors: students (13–18 years old) with basic IT knowledge

## ⚙️ Tech Stack
- Frontend: Angular
- Backend: Django + Django REST Framework
- Database: PostgreSQL (or SQLite for development)

## 🚀 Features (MVP)
- User registration/login (JWT)
- Create job request
- View job list
- Accept job
- Basic profile system

## 📦 Future Improvements
- Rating system
- Chat between client and executor
- Payment integration
- Admin moderation panel
